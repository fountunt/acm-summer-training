# 对拍（Duipai）

用随机数据对比「暴力程序」与「算法程序」的输出,验证算法正确性。

## 文件
| 文件 | 作用 |
| --- | --- |
| `gen.cpp` | 数据生成器:随机造一组输入,写到 stdout |
| `bf.cpp` | 暴力程序:只求正确(枚举/爆搜/朴素模拟),作为标准答案 |
| `std.cpp` | 待验证程序:你的算法代码 |
| `duipai.sh` | 对拍脚本:循环跑,输出不一致即停 |

## 使用
```bash
# 三个源文件放在同一目录
bash duipai.sh         # 跑 1000 轮
bash duipai.sh 10000   # 跑 1 万轮
```

出 WA 时脚本打印:输入(`data.in`)、你的输出(`std.out`)、标准答案(`bf.out`),直接本地调试。

## 要点
- **数据要小**(n ≤ 10 量级),暴力才跑得完;同时造边界结构(全 0、单元素、最大数、递减序列等)
- 出错后保留 `data.in`,或在 `gen.cpp` 里把 `rng` 种子固定,便于复现
- 多测数据:生成器里循环输出多组 `T`,注意每组格式一致
- 构造题有多解不能 `diff`,需写 checker 判断合法性(Special Judge)
- 暴力小数据通过后,可另写一份大数据生成器只测 `std` 的时限/内存
