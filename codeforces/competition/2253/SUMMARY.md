# CF Round 2253 补题题解

## E. Diameter Intersections

- **题意：** 给一棵直径长度为**奇数**的树。称整数 k 为美丽的,当且仅当能选出两条直径(允许相同,也允许端点相同),使得它们的交集恰好包含 k 条边。输出所有美丽 k(升序)。

### 核心结论

1. **奇直径 ⇒ 唯一中心边。** 直径 D = 2m+1 的中心是唯一一条边 (a,b),且**所有直径都必须经过它**。(偶数直径的中心是唯一顶点;奇数时顶点数 L+1 为偶数,正中间是一道"缝隙"→ 一条边)
2. **直径端点 = 两侧最远点。** 沿 (a,b) 把树切成两半:任一侧顶点到 a/b 的距离 ≤ m(否则能拼出比 D 更长的路径),而直径的存在要求两侧各有一个深度恰为 m 的点。所以**直径 = A 侧深点 ↔ B 侧深点的路径**。
3. **交点结构。** 两条直径 (X₁,Y₁)、(X₂,Y₂) 都过中心边,交点为:
   `[a 到 lca(X₁,X₂) 的公共前缀] + 中心边 + [b 到 lca(Y₁,Y₂) 的公共前缀]`
   ⟹ **k = d₁ + 1 + d₂**
4. **可达深度集合。** A 侧深度 d 可达 ⟺ 存在两个深点其 lca 深度为 d:
   - 深度 d 的某点有 **≥2 个分叉各含一个最远点** → 取两个深点分居不同分叉,lca 恰在该点;
   - 深度 **m 恒可达**(取 X₁=X₂,即两条直径选同一条)。
5. **合并两侧 = 布尔卷积。** 答案 = {1 + d₁ + d₂},是两侧深度集合的 Minkowski 和,用 NTT 卷积后取系数非零的位置。

### 算法流程

```
① 两次 BFS 求直径,提取路径,取中心边 (a,b)
② side(a,b) / side(b,a):
   一次 BFS 定深度 + 后序统计 cntU(子树内最远点数)、childU(含最远点的孩子数)
   childU ≥ 2 的深度记入集合;深度 L(=m) 无条件记入
③ PA、PB 为两侧深度集合的指示多项式 → NTT 卷积
④ C[t] > 0 的位置输出 t+1
```

### 为什么用 NTT

- 两侧深度集合最坏各 5×10⁵ 个,暴力双重循环 O(n²) 不可行;
- 卷积系数 = 和为 t 的 (d₁,d₂) 对数 ≤ 5×10⁵ << 998244353,模数下为精确整数,不会假 0;
- 998244353 = 119·2²³+1,支持长度 ≤ 2²³ 的 NTT,need ≤ n+1 够用。

### 复杂度

- 时间:O(n log n)/test(BFS ×4 为 O(n),NTT 为 O(n log n));Σn ≤ 10⁶
- 空间:O(n)

### 易错点

- **深度 m 必须恒可达**:题目允许两条直径完全相同,此时交 = 整条直径 k = D。漏掉这条,孤立侧(只有一个深点)会少答案。
- 所有直径都含中心边 ⇒ **k 恒 ≥ 1**,答案不会出现 0。

### 答疑(常见疑问)

**Q1: 为什么奇数长度意味着"正中间有一条边"?**

一条路有 L 条边就有 L+1 个顶点:

- L 为偶数 → 顶点数为奇数 → 正中间站着一个**顶点**(唯一的中心点)
- L 为奇数 → 顶点数为偶数 → 正中间是"缝隙" → 恰好是一条**边**

直径 D = 2m+1 时,中心边两侧各 m 条边。代码里 `m = D/2`,`a = path[m]`, `b = path[m+1]` 就是这条中心边。

**Q2: 为什么只切一刀,不是递归分治?**

- 所有直径都被"卡"在中心边上,两条直径的交永远包含中心边 → 问题被压成**两个互不相关的一维小问题**:"左侧两个最远点在哪分岔"、"右侧同理";
- 每侧的小问题一遍后序扫描就出答案(数子树里最远点的个数),**不存在更深的结构需要再切**;
- 递归分治是给"信息分散"的问题用的;这里信息全部集中在切刀处,一刀切开、两侧独立扫完即结束。

**Q3: NTT 加速的是"分治"吗?**

不是。NTT 只加速最后一步:**把所有 d₁、d₂ 配对求和**({1 + d₁ + d₂} 的布尔卷积)。树的处理全是 O(n) 的线性扫描;暴力配对是 O(|SA|·|SB|) = O(n²),NTT 降到 O(n log n)。

**Q4: 白话理解**

所有直径都过同一座"桥"(中心边)。两条直径的交 = 桥 + 桥两侧各重合到"岔路口"为止。某侧"能重合多长"由岔路口深度决定:深度 d 处有 ≥2 个分叉各藏一个最远点 → 重合 d;深度 m 恒可达(两条直径选同一条,即 X₁=X₂)。
