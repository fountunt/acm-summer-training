# K 核与最小不动点传播（K-Core & Fixed-Point Propagation）

## 概念

有一类问题要计算满足「**局部条件**」的最大集合 R：
- 图的 **k-核（k-core）**：删到每个点度数 ≥ k 的最大子图。
- 博弈必胜态：一个顶点必胜，当它满足「有 ≥ k 个邻居已在必胜集 / 目标集」等条件。

这类问题用**队列（BFS）传播**求**最小不动点**：从种子集出发，每当一个点满足条件就加入，
并更新其邻居的计数，反复扩散。每个点最多入队一次，总复杂度 O(n + m)。

---

## 通用框架 — O(n + m)

```cpp
#include <bits/stdc++.h>
using namespace std;

// 求集合 R：满足 |N(v) ∩ (S ∪ R)| >= need[v] 的最大集合（最小不动点）
// S：初始种子（已满足条件），need[v]：每个 v 需要的"合格邻居"个数
vector<char> fixed_point(int n, const vector<vector<int>>& adj,
                         const vector<int>& need, const vector<char>& S){
    vector<char> inR = S;                    // R 初始 = S
    vector<int> cnt(n, 0);                   // cnt[v] = |N(v) ∩ (S ∪ R)|
    for(int v=0; v<n; v++)
        for(int w : adj[v]) if(S[w]) cnt[v]++;

    queue<int> q;
    for(int v=0; v<n; v++)
        if(!inR[v] && cnt[v] >= need[v]){ inR[v]=1; q.push(v); }

    while(!q.empty()){
        int v = q.front(); q.pop();
        for(int w : adj[v]){
            if(inR[w]) continue;
            if(++cnt[w] >= need[w]){ inR[w]=1; q.push(w); }   // 达到阈值，加入并扩散
        }
    }
    return inR;                              // 最终 R（包含 S）
}
```

> 变体：若条件不是「≥ k 个邻居」，而是其它局部谓词，同样用"入队后更新邻居计数 / 状态、达标即入队"的思路。

## 模板题应用示例 2：迭代固定点（区间可达性）

> 来源：牛客多校「排列问题」。类内每个值 v 的可达区间 `[L_v,R_v]` 与「门值 mn」互为依赖，
> 也是单调不动点，用类似"传播"的迭代收敛（实测 ≤ 5 轮）。
> 当状态单调（只增不减）时，队列传播或迭代到稳定都能保证正确性。

## 注意事项

| 要点 | 说明 |
|------|------|
| 单调性 | 集合 R 只增不减，才能用队列传播；若条件可撤销则需换方法 |
| 阈值 need[v] | 每个点的阈值可以不同（如 k-core 用统一 k，博弈题用 2） |
| 计数更新 | 入队 v 时，给 v 的每个未入队邻居 cnt+1，达标即入队 |
| 初值 cnt | 先算种子 S 对每个点的贡献（如特殊邻居数），再检查是否直接达标 |
| 判"是否还有遗漏" | 传播结束后，集合即最大满足局部条件的集合（最小/最大不动点） |
| 复杂度 | 每条边被检查常数次，O(n + m) |
