# 取模构造：x = y + z（Modulo via Sum）

## 概念

当题目要求构造三元组满足 `x mod z = y` 时，**最省心的构造是直接令 `x = y + z`**：

> 只要 `0 ≤ y < z`，则 `(y + z) mod z = y` 恒成立（商为 1，余数为 y）。

于是"满足取模等式"就退化成"把数配成 `y`、`z`、`y+z` 三份，且保证 `y < z`"。剩下要解决的只是**用哪些数、怎么不重不漏覆盖整个整数集合**。

---

## 通用套路：中心点 + 互补对

要把 `0..3N-1` 分成 N 组 `(x,y,z)`，每组满足 `x mod z = y`，常用：

- 挑一两个**中心点**（如 `A`、`B`），每组取 **中心点两侧的一对互补数** 作为 y、z，再让 x = y+z；
- 补一两个**特殊三元组**处理中心点本身、0、以及边界最大数（靠 `x = 2·中心` 或 `z = 1` 保证合法）。

对任意一组 `(A + i, 2i, A - i)`：`x = (2i) + (A - i) = A + i` ✓，且 `2i < A - i` 只要 `i` 不超过 `A/3` 即可。

---

## 应用示例：把 {0,1,...,3N-1} 分成 N 个取模三元组（牛客暑期多校 H 题）

记 `A = N + ⌊N/2⌋`，`B = 2N + ⌊N/2⌋`（≈ 1.5N、2.5N 两个中心）。

**N 为奇数**：先输出 `(3N-1, 0, A)`（因为 `3N-1 = 2A`，模 A 余 0）；再对 `1 ≤ i ≤ ⌊N/2⌋` 输出
```
(A + i, 2i, A - i)
(B + i - 1, 2i - 1, B - i)
```

**N 为偶数**：先输出 `(B, N, A)`（因为 `B = A + N`，模 A 余 N）；再对 `1 ≤ i < N/2` 输出
```
(B + i, 2i, B - i)
(A + i + 1, 2i + 1, A - i)
```
最后输出 `(A + 1, 0, 1)`（任何数模 1 余 0）。

```cpp
#include <bits/stdc++.h>
using namespace std;
int main(){
    ios::sync_with_stdio(false); cin.tie(nullptr);
    long long N; cin >> N;
    long long A = N + N/2, B = 2*N + N/2;
    if (N % 2) {
        cout << 3*N - 1 << ' ' << 0 << ' ' << A << '\n';
        for (long long i = 1; i <= N/2; ++i) {
            cout << A + i << ' ' << 2*i << ' ' << A - i << '\n';
            cout << B + i - 1 << ' ' << 2*i - 1 << ' ' << B - i << '\n';
        }
    } else {
        cout << B << ' ' << N << ' ' << A << '\n';
        for (long long i = 1; i < N/2; ++i) {
            cout << B + i << ' ' << 2*i << ' ' << B - i << '\n';
            cout << A + i + 1 << ' ' << 2*i + 1 << ' ' << A - i << '\n';
        }
        cout << A + 1 << ' ' << 0 << ' ' << 1 << '\n';
    }
    return 0;
}
```

复杂度：O(N)。覆盖验证：奇数时各段拼成 `0..6k+2 = 0..3N-1`，偶数时拼成 `0..6k-1`，恰好一次。

---

## 要点

| 要点 | 说明 |
|------|------|
| 核心恒等式 | `0 ≤ y < z ⟹ (y+z) mod z = y` |
| 保证 y<z | 用中心点控制 i 的范围（`3i < A`）或让 y 是小偶数/小奇数 |
| 特殊三元组 | 处理边界：`x = 2·中心`（中心是 x 的一半）或 `z = 1`（模 1 恒为 0） |
| 覆盖检查 | 把每组用到的数按区间拼起来，核对是否恰好铺满目标集合 |
| 识别特征 | "把 0..3N-1 分成取模三元组"、"每数恰用一次 + x mod z = y" 类构造题 |
