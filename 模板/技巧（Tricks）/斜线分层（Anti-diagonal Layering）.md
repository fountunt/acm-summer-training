# 斜线分层（Anti-diagonal Layering）

## 概念

适用于"矩阵 + 单调路径（只向右/向下）覆盖计数"类问题。

**核心观察**：无论向右 `(i,j)→(i,j+1)` 还是向下 `(i,j)→(i+1,j)`，`i + j` 都**恰好 +1**。因此一条从 `(1,1)` 到 `(n,m)` 的路径，必然**每个反斜线层 `s = i+j` 恰好经过 1 个格子**。

于是"每条路径经过某格子几次"就可以按层拆成**流量**：从 `(1,1)` 出发，逐层传到 `(n,m)`。每层一个格子就是一个"流量节点"，需求 = 该格子必须被覆盖的次数。

- 层数 = `n+m-1`，`s` 取值 **2 ~ n+m**（不是 min(n,m)！）
- 每层最多格子数 = min(n,m)（中间几条斜线）

```
s=2: (1,1)
s=3: (1,2) (2,1)
s=4: (1,3) (2,2) (3,1)
...     （每条路径从 s=2 走到 s=n+m，每层踩 1 格）
```

---

## 核心模型（逐层流量 + 前缀和条件）

设当前层第 `r` 行的需求为 `b_r`，下一层第 `r` 行的需求为 `c_r`。

**层间传递规则**：`b_r` 只能流到下一层的第 `r` 行（向右）或第 `r+1` 行（向下）。

下一层第 `r` 格的需求 `c_r`，只能由 **同行走下来的** `f_r` + **上方行流下来的** `carry` 补足：

```
c_r = f_r + carry
```

因为 `carry`（上一行的剩余流量 `g_{r-1}`）已在前一行定死，`f_r` 被**唯一确定**，没有选择空间：

```
f_r = c_r - carry          carry 初始为 0（第 1 行上方没有流量）
g_r = b_r - f_r            （本行剩余流量向下，成为下一行的 carry）
```

**可行性条件**（逐行检查 `0 ≤ f_r ≤ b_r`）：

```
0 ≤ c_r - carry ≤ b_r
⇔  B_{r-1} ≤ C_r ≤ B_r     （B、C 为 b、c 的前缀和）
```

且最后一行结束后 `carry = 0`（最后一行不能再向下）⇔ `B_n = C_n`（整层总量守恒）。等价地，`carry` 就是实时维护的**前缀和差**：`carry_r = B_r - C_r`。

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

// ====== 核心：相邻两层的流量可行性检查 ======
// cur[r] = 当前层第 r 行需求量（格子不存在则为 0，视为无流量）
// nxt[r] = 下一层第 r 行需求量（同上）
// 返回 cur 的流量能否合法地全部流入 nxt
bool transfer(const vector<ll>& cur, const vector<ll>& nxt) {
    int n = (int)cur.size() - 1;
    ll carry = 0;                     // 上方流下来的流量 g_{r-1}
    for (int r = 1; r <= n; ++r) {
        ll need = nxt[r] - carry;     // 必须由本行"直走"补的流量 f_r
        if (need < 0 || need > cur[r]) return false;  // 本行给不出 / 上方流太多
        carry = cur[r] - need;        // 本行剩余流量向下
    }
    return carry == 0;                // 最后一行不能再向下（总量守恒）
}

// ====== 应用：L-Matrix（所有操作把单调路径格子 +1，使矩阵全相等） ======
// 目标 X、操作次数 K 由 (1,1) 与第二步唯一消元：
//   K = a12 + a21 - 2*a11,   X = a11 + K
// 每格需被覆盖 X - a[i][j] 次，逐层检查流量可行性。
ll L_solve(int n, int m, const vector<vector<ll>>& g) {
    // 1) 单行 / 单列：唯一路径覆盖整行(列)，每次操作所有格子一起 +1，差值不变
    if (n == 1 || m == 1) {
        for (int i = 1; i <= n; ++i)
            for (int j = 1; j <= m; ++j)
                if (g[i][j] != g[1][1]) return -1;
        return 0;
    }

    // 2) 候选解唯一
    ll K = g[1][2] + g[2][1] - 2LL * g[1][1];
    if (K < 0) return -1;
    ll X = g[1][1] + K;

    // 3) 每个格子需被覆盖次数非负
    for (int i = 1; i <= n; ++i)
        for (int j = 1; j <= m; ++j)
            if (X - g[i][j] < 0) return -1;

    // 4) 逐层流量分配
    vector<ll> cur(n + 1), nxt(n + 1);   // 已清零
    cur[1] = X - g[1][1];                // 初始层 s=2 只有 (1,1)
    for (int s = 2; s < n + m; ++s) {    // 循环体算下一层 s+1，故 s 最多取到 n+m-1
        for (int r = 1; r <= n; ++r) {   // 下一层 s+1 的需求
            int c = s + 1 - r;
            nxt[r] = (c >= 1 && c <= m) ? X - g[r][c] : 0;
        }
        if (!transfer(cur, nxt)) return -1;
        cur.swap(nxt);
    }
    return K;
}
```

## 使用方式

| 场景 | 处理 |
|------|------|
| **路径覆盖计数 / 目标元素相等** | 先消元求唯一候选 → 检查非负 → 分层贪心 |
| **纯可行性判定** | 直接用 `transfer(cur, nxt)` 逐层判 |
| **需求值可能很大** | 全部用 `ll`（候选 X 可能到 ±1e9 量级） |

**识别特征**：路径只右/下、把路径格子集体 +1/-1、问能否全体相等/最少操作数 → 想到 `i+j=s` 分层 + 逐层流量。

---

## 要点

- **层数 = n+m−1，不是 min(n,m)**；min(n,m) 只是每层最多格子数
- **循环上界 `s < n+m`**（循环体算下一层 `s+1`）：多跑一次就凭空多一层，`carry≠0` 全判无解
- **列越界判断写 `c <= m`**（写错成 `n` 会在非方阵上越界 UB 或漏列）
- 读入、单行/列特判的循环下标保持 **1 起始**（g 是 1 起始的）
- `carry` 实时维护的正是前缀和差 `B_r − C_r`，等价于题解的 `B_{r-1} ≤ C_r ≤ B_r`
- 该层每个格子的"需求"若可由同层其他格子的需求推出来（如本问题由 X 统一给出），先算好再逐层转移
- 复杂度 O(n·m)，转移部分只需 O(n) 额外空间
