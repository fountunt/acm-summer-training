# 位运算与掩码可行性贪心（Bit Ops & Mask Greedy）

## 概念

两个可复用的部分：

1. **位运算速查**——单比特 / 掩码的常用操作与 GCC 内建函数，随手翻；
2. **掩码可行性贪心**——一类题的模式：操作花费 = 数值本身、可任意作用于子集时，把操作**按位拆解**成「买位」模型；配合**超递增权重**（高位比所有低位之和还贵）从高位到低位**贪心删位**；固定掩码下的可行性用「贪心取 ≥ m 的最小可达值」判定。

> 贯穿例子：牛客多校「入侵天使领域行动」。n 个模块，每次选 k 花费 k 可异或任意子集，求使数组单调不降的最小总花费。

## 一、位运算常用公式速查

### 单比特操作（掩码全部用 `ll`，位上限 B ≤ 62）

| 操作 | 代码 | 说明 |
|------|------|------|
| 取第 k 位 | `(x >> k) & 1` | 结果为 1 ⟺ 第 k 位为 1 |
| 第 k 位置 1 | `x \|= (1LL << k)` | |
| 第 k 位置 0 | `x &= ~(1LL << k)` | `~` 符号扩展无碍（见注意事项） |
| 第 k 位取反 | `x ^= (1LL << k)` | |
| 保留第 0..k 位 | `x & ((1LL << (k+1)) - 1)` | 低 k+1 位全 1 掩码 |
| 清除第 0..k 位 | `x & ~((1LL << (k+1)) - 1)` | 只留 k 位以上 |
| 低位 k 个 1 的掩码 | `(1LL << k) - 1` | 即 0b…000111 |

### 定位类（GCC 内建，参数建议用无符号）

| 操作 | 代码 | 说明 |
|------|------|------|
| 最低位 1（lowbit） | `x & -x` | 只留最右一个 1 |
| 去掉最低位 1 | `x & (x - 1)` | 每调用一次消一个 1 |
| 最低位 1 的位置 | `__builtin_ctzll(x)` | trailing zeros；x=0 未定义 |
| 最高位 1 的位置 | `63 - __builtin_clzll(x)` | leading zeros；x=0 未定义 |
| 1 的个数 | `__builtin_popcountll(x)` | |
| 下取整到 2 的幂 | `1LL << (63 - __builtin_clzll(x))` | x>0 |
| 判断是 2 的幂 | `x && !(x & (x - 1))` | |
| 相邻位 | `(x & (x >> 1))` 非零 | 存在相邻两个 1 |

> 枚举子集 `for(sub = S; sub; sub = (sub-1) & S)` 与 SOS DP 见 **DP 模板「状压 DP」**，此处不重复。

## 二、核心技巧：按位拆解 + 超递增权重 + 掩码可行性贪心

### 1. 按位拆解：把「操作花费 = 数值」变成「买位代价 = 掩码值」

一次操作 `k = Σ_{b∈bits(k)} 2^b`。把它拆成若干次只异或一位 `2^b` 的操作，每次可作用于**不同**子集，总花费不变（Σ2^b = k）。

于是每位的决策只有：**买**（花 2^b，可翻任意子集的该位）或**不买**（花 0）。总花费 = 所买位集合的数值 `value(B) = Σ_{b∈B} 2^b`。

### 2. 固定位 / 自由位（轨道）模型

买下的掩码 `B`：
- **自由位** = B 中为 1 的位，元素可翻转；
- **固定位** = `~B` 中为 1 的位，锁死不能动。

元素 x 的可达集合（轨道）：

```
orbit(x) = { v : v & ~B == x & ~B }
f = x & ~B        // 锁死且为 1 的位（输入给 nxt）
```

### 3. 固定掩码的可行性：贪心取「≥ m 的最小可达值」

从头到尾维护 `m` = 前缀最后一个元素能取到的最小值。对每个 x，在轨道里取 ≥ m 的最小值 `v`（用 `nxt`），取不到 → 该掩码不可行。取最小给后面留最大余地，故「贪心能走通 ⟺ 方案存在」。

`nxt(m, B, f)`：求轨道中 ≥ m 的最小值，思路是**高位保持 m、在 m 的某个 0 位上抬 1、低位压到最小**：

```cpp
ll nxt(ll m, ll B, ll f){
    if(m < 0) return f;                        // 第一个元素，无下限 → 取轨道最小 f
    if((m & ~B) == f) return m;                // m 本身满足锁定位 → 直接用 m
    for(int i = 0; i <= 29; i++){              // 从低到高找能抬的位（抬越低增量越小）
        if((m >> i & 1)) continue;             // m 在此位已是 1，抬不动
        if(((m >> (i+1)) & ~(B >> (i+1))) != ((f >> (i+1)) & ~(B >> (i+1)))) continue;  // 高位锁定位必须一致
        if(!(B >> i & 1) && !(f >> i & 1)) continue;   // 锁死成 0 的位设不了 1
        ll v = (m & ~((1LL << (i+1)) - 1));    // 高位 = m
        v |= (1LL << i);                       // 位 i 抬成 1 → v > m
        v |= (f & ~B & ((1LL << i) - 1));      // 低位：锁定位取 f，自由位取 0（最小化）
        return v;
    }
    return -1;                                 // 轨道里没有 ≥ m 的值
}
```

### 4. 超递增权重 → 从高到低贪心删位

可行性关于掩码**单调**（多加位只会更好做）；权重**超递增**：`2^b > 2^0+…+2^{b-1}`。所以**能删高位必须删**（省 2^b，最坏补全低位也才 2^b−1），贪心高→低删位就是最优：

```cpp
ll M = (1LL << 30) - 1;               // 全位可翻，必然可行（起点）
for(int b = 29; b >= 0; b--)
    if(feasible(M & ~(1LL << b), a))  // 不买位 b 仍可行？
        M &= ~(1LL << b);             // 是 → 锁死它，省下 2^b
// 最终 M 的数值 = 最小总花费
```

### 5. 完整代码（A 题）

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

ll nxt(ll m, ll B, ll f){
    if(m < 0) return f;
    if((m & ~B) == f) return m;
    for(int i = 0; i <= 29; i++){
        if((m >> i & 1)) continue;
        if(((m >> (i + 1)) & ~(B >> (i + 1))) != ((f >> (i + 1)) & ~(B >> (i + 1)))) continue;
        if(!(B >> i & 1) && !(f >> i & 1)) continue;
        ll v = (m & ~((1LL << (i + 1)) - 1));
        v |= (1LL << i);
        v |= (f & ~B & ((1LL << i) - 1));
        return v;
    }
    return -1;
}

bool feasible(ll B, const vector<int>& a){
    ll m = -1;
    for(int x : a){
        ll v = nxt(m, B, (ll)x & ~B);
        if(v < 0) return false;
        m = v;
    }
    return true;
}

void solve(){
    int n; cin >> n;
    vector<int> a(n);
    for(int i = 0; i < n; i++) cin >> a[i];

    ll M = (1LL << 30) - 1;
    for(int b = 29; b >= 0; b--)
        if(feasible(M & ~(1LL << b), a))
            M &= ~(1LL << b);
    cout << M << "\n";
}

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t; cin >> t;
    while(t--) solve();
    return 0;
}
```

## 使用方式

| 场景 | 处理 |
|------|------|
| 操作花费 = 数值、可作用任意子集 | 按位拆解 → 买位模型 `value(B)` |
| 权重 2^b 超递增 + 可行性单调 | 高→低贪心删位（能删必删） |
| 固定掩码可行性判定 | 贪心取「≥ m 的最小可达值」（`nxt`） |

**识别特征**：操作值任意、可任选子集、目标满足某种单调性质（非降/相等…）、求最小总花费 → 按位拆解 + 掩码贪心。

## 注意事项

| 要点 | 说明 |
|------|------|
| `~` 符号扩展 | `x & ~B` 中 `~B` 高位全 1，但 `x < 2^30` 高位为 0，相与后高位仍 0，安全；掩码统一用 `ll` |
| 位上限 | 值域 10^9 < 2^30，只枚举位 0..29；循环 `i <= 29`，构造 `1LL << 30` 在 `ll` 内安全 |
| 内建函数 x=0 | `__builtin_ctz/clz` 对 0 未定义，先判 `x` 非 0 |
| `nxt` 三条件 | m 已是 1 / 高位锁定位不一致 / 锁死成 0 的位，都被跳过，只抬最低合法位 |
| 复杂度 | 每次可行性 O(30·n)，30 个掩码 → O(30²·n)，n=2×10⁵ 实测约 93ms |
| 贪心正确性 | 每步取最小才保证「贪心走通 ⟺ 方案存在」；大数能缩就缩 |
